# Ручная проверка конкурсной версии Muras

Чек-лист дополняет [release-readiness.md](release-readiness.md). Пункты ниже — шаги
для реального устройства/хостинга и сценарии, которые нельзя заменить оценкой Lighthouse.
Не отмечать их выполненными только на основании автоматических тестов.

## Изолированный полный цикл /admin — обязательный перед публикацией

Автоматизированный аналог проходит в `tests/release.test.mjs`: Vue-контроллер, сохранение,
экспорт, полный генератор с фото/картой/викториной, публичные Vue-шаблоны и Canvas crop.
**Ручной импорт в браузере агента ранее был запрещён разрешением Browser Use. Запрет
не обходился; ниже инструкция для владельца, который сам выбирает файл.**

1. Создать временную копию проекта с текущего коммита (в отдельной папке/Git worktree).
   Копировать исходные данные и фото; не заменять файлы основного рабочего дерева.
   В копии выполнить `npm ci`, `npm run build`, `npm run preview -- --port 4180`.
   Другой порт отделяет её localStorage от основной демонстрации.
2. Открыть `http://localhost:4180/admin`. Нажать «Импорт source JSON», выбрать
   **файл из временной копии** `data/species.source.json`. Должны появиться 9 видов;
   редактор не должен обещать публикацию на сервер.
3. Открыть ирбиса → «Фотографии» → разрешённое первое фото. Не менять названия,
   угрозы, источники, численность, лицензии, verified или дату научной проверки.
4. Для «Карточка каталога» задать Zoom=1.20, Horizontal=0.40, Vertical=0.60;
   для «Подробная карточка» — 1.40/0.45/0.50; для «Режим преподавателя» — 1.10/0.50/0.55.
   Эти значения — тест композиции, не научные сведения. Проверить мышь, касание,
   клавиатурные стрелки ползунков, сброс и предупреждение о разрешении.
5. Проверить четыре предпросмотра: карточка, подробный кадр, Canvas, урок. Canvas
   должен совпадать с **detail**, даже когда редактируется card или lesson.
   Осмотреть головы, глаза и важные элементы снимка; не увеличивать ради «восстановления» деталей.
6. Сохранить черновик, обновить страницу, снова открыть ирбиса. Значения композиции
   должны восстановиться. Для нового локального файла после reload надо выбрать
   тот же финальный WebP снова: байты/Blob URL не хранятся в localStorage.
7. Нажать «Проверить данные», затем «Экспорт source JSON». В копии проекта сравнить
   экспорт с оригиналом: изменены только `images[].compositions`; архив, все языки,
   источники и исходные скрытые поля сохранены. Не принимать public/data/species.json за source.
8. Заменить **только source во временной копии** экспортом. Выполнить `npm run data`,
   `npm run data:validate`, `npm test`, `npm run build`.
9. Перезапустить preview копии. Открыть каталог/ирбиса/визуализацию/урок: применяются
   соответствующие настройки; фото и источники прежние, неизвестная численность не ноль.
10. Проверить «Предыдущий черновик», сброс с отменой и подтверждением, предупреждение
    beforeunload при несохранённой правке. Исходная основная ветка должна остаться чистой;
    тестовый source и изображения не коммитить. Закрыть/удалить временную копию штатным способом.

## Реальные экраны, клавиатура и масштаб

- [ ] Телефон 320/375 px и планшет: портрет → альбом → портрет с открытым диалогом;
  содержимое прокручивается, кнопка закрытия остаётся доступной, фон неподвижен.
- [ ] Chrome/Edge: масштаб **100%, 125%, 200%**, возврат к 100%. Проверить шапку,
  фильтры, карту, диалог, урок, вопросы, поддержку и вкладки/ползунки админки.
- [ ] Пройти навигацию Tab/Shift+Tab; виден фокус; в диалоге фокус не уходит в фон;
  Escape и клик по backdrop закрывают окно, фокус и scroll возвращаются к инициатору.
- [ ] В fullscreen урока стрелки меняют вид; клавиши в select/input работают обычно;
  Escape/кнопка/переход к викторине не оставляют скрытый fullscreen.
- [ ] Включить системное reduced motion: эффекты не обязательны для доступа к сведениям.
- [ ] Screen reader (NVDA/VoiceOver): названия элементов включают видимые подписи,
  заголовки/статусы/источники/язык карточки читаются осмысленно.
- [ ] Firefox и Safari/WebKit: Canvas, object-position/zoom, native dialog и Fullscreen API;
  при отсутствии API работает обычная фотография/окно урока.

## Состояние и неисправности

- [ ] В отдельном профиле браузера первый визит KY; RU/EN переживают reload.
- [ ] Поиск/фильтры/область сохраняются при переходах разделов и сбрасываются при reload.
  Не считать это потерей сохранённых пользовательских данных: они сеансовые.
- [ ] Завершить викторину, проверить процент и запрет повторного ответа; reload показывает
  последний результат. Новое прохождение и повтор ошибок доступны после результата.
- [ ] Добавить выдуманный QA-псевдоним, reload, удалить **только тестовую запись**;
  нет сумм, рейтинга, обещания пожертвования или видимости для других пользователей.
- [ ] В тестовом профиле повредить/устарить отдельный ключ языка/quiz/wall/admin через
  DevTools Application. Нет аварии и ложного успеха сохранения; исходные записи основного
  профиля не трогать. Для admin ошибка не должна заменять публичный каталог черновиком.
- [ ] Заблокировать storage или заполнить квоту в отдельном профиле: редактор сообщает
  ошибку, сохраняет индикатор правок, валидный экспорт остаётся доступен.
- [ ] DevTools Network → Offline: после загрузки изучить уже загруженные разделы;
  незагруженное фото даёт placeholder/сообщение. Свежая загрузка без сети не обещает
  офлайн-приложение: Service Worker/PWA в проекте нет. Восстановить Online и обновить страницу.
- [ ] В тестовой копии заблокировать один image URL: каталог/диалог/урок/quiz остаются
  доступными, атрибуция сохраняется. Заблокировать JSON — показывается ошибка загрузки.
- [ ] Memory/Performance: 30–50 открытий с завершением эффектов; сравнить heap после GC,
  проверить detached nodes, GPU/decoded image memory и frame time во время прокрутки.
  Не трактовать HTTP-cache или рост до GC как доказательство утечки.

## Реальный хостинг

- [ ] Публикуется только `dist`, не репозиторий, source JSON, резервные копии или .git.
- [ ] HTTPS, прямой `/` и `/admin`, reload. Есть SPA fallback или папка admin/index.html
  с redirect `/admin` → `/admin/`. Реальные assets/JSON/robots/favicon имеют правильные MIME.
- [ ] Неизвестные API/служебные пути и отсутствующие файлы желательно возвращают 404,
  а не HTML, замаскированный под JSON/robots. `/admin` — локальный инструмент, не защита паролем.
- [ ] Для подпапки настроены Vite base и корневой robots.txt хостинга; `/admin` в Disallow
  нужно адаптировать к реальному пути. Robots не является авторизацией.
- [ ] Хешированные JS/CSS можно кэшировать immutable; JSON и фото с прежними именами
  должны ревалидироваться. Не назначать вечный кэш `/images/approved/irbis-1.webp`.
- [ ] Проверить title/description/OG на KY/RU/EN и favicon. Без JS — исходный KY head;
  canonical/og:url/социальные ссылки без настоящего домена не выдумывать.
- [ ] Выполнить Lighthouse на настоящем HTTPS-хосте и слабом реальном телефоне;
  повторить 3–5 раз, сравнить медианы; собрать полевой INP/LCP/CLS при достаточном трафике.
- [ ] Сохраняются verified:false, null численности, исторические национальные категории,
  оригинальные научные источники, условия фото и честная демостена.

Не подключать backend/платежи ради прохождения этих пунктов. Совместное редактирование,
авторизация, серверная публикация и аудит версий относятся к будущему Django.
