# Muras — готовность конкурсной версии, задача №15

Аудит выполнен 13 октября 2026 года в `competition-v1`, исходный коммит `16a9b23`.
Объём: стабильность, производительность, состояние, публикация и регрессия.
Научная база, фотографии, лицензии, verified, логотип, палитра и композиция не изменены.
Новые runtime-зависимости, backend, PWA и крупные функции не добавлены.

## Решение о готовности

**Конкурсная сборка проходит автоматические проверки и доступные браузерные сценарии.**
Перед размещением на реальном хостинге нужны проверки его маршрутов/кэша/HTTPS,
ручной цикл административного импорта из чек-листа и проверка целевых устройств.
Это не независимое подтверждение научной базы и не разрешение на действующие пожертвования.

## Критический цикл админки

Новый интеграционный тест использует **временную копию** source/географии/quiz и
разрешённых оригинальных фото. Через настоящий Vue-контроллер импортирует документ,
выбирает ирбиса, меняет только card/detail/lesson composition, сохраняет, повторно
читает draft, экспортирует полный JSON. Проверяет:

- исходные поля/переводы/источники/архив сохранены; если убрать только тестовые
  compositions, документ равен исходному;
- export принимается validateSource, generateAllData и его --check-эквивалентом;
- фото копируется побайтово, sha256 проходит; исходный файл основного проекта не изменён;
- реальные публичные Vue-шаблоны card/modal visualization/lesson содержат нужный crop;
- Canvas получает detail crop из той же геометрии, без повторной деградации оригинала.

Публичный admin использует localStorage/скачивание JSON, не имеет API записи.
Проверен код репозитория и export/import, публичные данные отделены от черновика.
В preview private source и .git не раскрываются: запросы к их путям возвращают HTML
fallback, не содержимое файлов. Это не идеальный 404 и не подтверждение конфигурации
будущего хостинга; публиковать весь репозиторий нельзя.

**Браузерный импорт ранее был отклонён разрешением Browser Use; его не повторяли
и не обходили через подстановку state/сервер fixtures/другой браузер.** Node/Vue тесты
не отправляют source в браузер. Ручной цикл указан пошагово в
[manual-qa-checklist.md](manual-qa-checklist.md); drag/touch/export download в браузере
после импорта остаются непроверенными.

## Ограничения и оставшиеся действия

До публичного размещения: реальный хостинг/кэш/404/HTTPS; ручной admin workflow;
целевой телефон/проектор; Firefox/Safari/WebKit; zoom 125%/200%; screen reader;
Offline/плохая сеть и Memory/FPS профиль. Эти проверки не выдаются за проведённые.

Нужна независимая научная редактура и актуальная правовая проверка национального
статуса: все виды verified:false, неизвестная численность null, категории исторические.
Источник и licence metadata сохранены; повторная юридическая/научная экспертиза не выполнена.
Демостена не пожертвования; нет платежей/организации/сбора.

`npm audit`: 7 предупреждений (5 high, 2 moderate) в dev build dependency chain
Tailwind 3/braces/selector-parser; `npm audit --omit=dev`: **0**.
Проверены [braces advisory](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) и
[selector-parser advisory](https://github.com/advisories/GHSA-rj75-hqrm-r3gf).
Не выполнен audit fix --force с миграцией на Tailwind 4. Собирать только доверенный
код, не выставлять dev server наружу; отдельно запланировать совместимое исправление toolchain.
Это не уязвимость Vue runtime, выявленная данным аудитом, и не отменяет риск build chain.

До Django можно отложить auth/роли, совместное редактирование, серверную загрузку медиа,
ревизии/конфликты, серверную публикацию и отчётность. Для read-only конкурсного сайта
backend не является обязательным. Архитектура миграции уже в backend-migration.md.
