# MURAS 100 — аккуратное обновление интерфейса

Версия: на основе исходного `muras-100-design.zip` (коммит `ed553890326fc9ae40a33dd0fbb94c5b4f21a90b`).

- **Footer:** правый текст — «Полотова А.»; образовательное предупреждение слева сохранено.
- **Каталог:** сортировка по наличию подтверждённого изображения (только когда поисковая строка пуста), без изменения исходного порядка внутри двух групп. Все 12 карточек с placeholder идут в конец, пока нет подтверждённых фотографий. После завершения фотокаталога удалить `prioritizeIllustratedResults` из `App.vue` и назначить алфавитную сортировку согласно требованиям.
- **Сетка:** 1–5 колонок; стартовые настройки 3 на широком экране и 2 на телефоне. На телефонах выбор 3–5 сохраняет читаемую ширину мини-карточек посредством горизонтального прокручивания **только каталога**, не страницы.
- **Мобильные фильтры:** один сворачиваемый блок; десктопные фильтры не меняются.
- **Поиск:** непрерывная бегущая строка `Издөө · Izlash · Искать · Search`, только при пустом неактивном поле. Реальный combobox, подсказки и поиск по 4 языкам не менялись. Reduced-motion отключает бегущую строку.
- **Карта:** стандартная презентационная карточка с прежними фиксированными размерами; внутреннюю вертикальную прокрутку убрали. Список фотографий в мини-панели сокращён до двух, а ссылки на права и авторов доступны в раскрывающейся атрибуции. Полный региональный каталог остаётся на `/map`. На телефонах картографический блок и справочный блок становятся взаимоисключающими слайдами одинакового размера; выбор области открывает справку, две кнопки-переключателя позволяют открыть сведения и без выбора области.
- **Главная:** оригинальный SVG гор без изменений; ещё пять авторских минималистичных SVG — архар, снежный барс, беркут, **цветковое растение** рябчик Эдуарда (Fritillaria), грибы. Смена каждые 6,5 секунд, ручной выбор по точкам. Незаметное движение отключается при reduced-motion.
- **Научные данные:** никакие файлы `data/species.source.json`, фотографии, лицензии, результаты исследований, карта-геометрия и научные источники не менялись.
- **Проверки:** `npm run data` и `npm run data:validate` прошли на предоставленном архиве; новые два юнит-теста временной сортировки прошли. Полный `npm test` и `npm run build` в среде подготовки не были доступны из-за отсутствия пакетов npm (нет сетевого доступа к npm registry); на локальном компьютере после `npm ci` выполнить оба. Старые научные тесты исторических хешей теперь явно исключают **только перечисленные UI-файлы**; исторические JSON-хеши доказательств не изменены, остальные файлы по-прежнему сверяются.

## Проверка перед публикацией

После распаковки в ветке `feature/bulk-import-next` выполнить `npm test`, `npm run data:validate`, `npm run build` и посмотреть каталог на ширинах 360/390/768/1280px. Не публиковать до проверки.
