# Снимки первоисточников — 12.10.2026

Эта папка содержит неизменяемые свидетельства исследования, а не вторую базу видов.
Генератор и приложение **не читают** эти файлы. Редактируемый источник остаётся
`data/species.source.json`; публичный JSON — его генерируемая проекция.

- `iucn-dataset.json`: ответ официального API GBIF о наборе IUCN
  `19491596-35ae-4a91-9a98-85cf505f1bd3`; версия 2026-1, публикация 28.07.2026,
  издатель IUCN, DOI 10.15468/0qnb58, лицензия данных CC BY 4.0.
- `iucn-taxa.json`: принятые записи девяти видов из этого набора и точные URL запросов.
  Выбраны по canonicalName и taxonomicStatus=ACCEPTED, не по нечёткому совпадению.
  threatStatuses — глобальные категории IUCN; год выпуска набора не является годом оценки.
- `gbif-taxonomy-matches.json`: ответы GBIF Backbone `species/match` с strict=true;
  расхождения концепций видов объяснены в отчёте. Они не исправлялись автоматически.
- `commons-photos.json`: ответы Commons API о девяти оригинальных файлах: размеры,
  авторство, лицензии, страницы и метаданные. HTML внутри extmetadata — архивная
  цитата, не код для исполнения/публикации. API не заменяет чтение страницы файла.

Данные IUCN цитируются так: IUCN (2026). *The IUCN Red List of Threatened Species*.
Version 2026-1. Downloaded on 2026-07-28. https://doi.org/10.15468/0qnb58,
accessed via GBIF.org on 2026-10-12. Извлечённые/нормализованные категории и ранги
связаны с этим набором в sources; преобразования описаны в species-research.md.
При использовании этих извлечений сохраняйте атрибуцию IUCN/GBIF и
[условия CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Лицензии фотографий индивидуальные, они не заменяются лицензией данных IUCN или кода.
Сведения о каждом файле и изменениях находятся в основном JSON и отчёте.
