## Возникшие и устранённые проблемы

Первый полный прогон дал 11 ошибок: исторические тесты предполагали неизменный размер живого каталога 100 и отсутствие UZ-названий, а внутреннее сохранение админки отклоняло контейнер с двумя копиями выросшего каталога по лимиту одного документа.

Исторические проверки теперь используют точные снимки прежнего выпуска либо проверяют фактически указанные, подтверждённые названия и фотоквитанции. Старые evidence и их контрольные суммы не переписаны. Новые тесты отдельно проверяют весь действующий каталог и полную сохранность первых 100.

В `src/admin/data/repository.js` лимит внутреннего контейнера черновика составляет 4 МиБ + 64 КиБ для двух документов и метаданных; лимит импортируемого JSON остался **2 МиБ**. Проверены сохранение/восстановление каталога, отказ при превышении лимита и сохранность предыдущего черновика при ошибке. Историческая реализация сохранена с исходным SHA-256 для старых аудитов. Дизайн, компоненты интерфейса, анимации и карта не изменялись.

**Нерешённых проблем нет.** Независимая научная проверка остаётся pending согласно разрешению владельца; это ожидаемый статус, а не научное одобрение.
