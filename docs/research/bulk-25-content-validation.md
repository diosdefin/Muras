# MURAS — проверка партии 25 научных черновиков

> Исторический отчёт задачи 22.3. Последующий [аудит 22.4](bulk-25-release-audit.md) выявил два существенных таксономических противоречия: актуальное состояние — 23 `ready_for_review`, 2 `needs_evidence`. Приведённые ниже результаты относятся к завершению 22.3 и не являются текущим разрешением импорта.

Дата исследования: 14 октября 2026 года. Ветка: `feature/bulk-import`. Проверенный исходный HEAD: `006235532cc14e3ec26ccd9c56c9e6fd083f30e9`; рабочее дерево перед началом было чистым. Пять блоков завершены последовательно; импорт, approve, apply, push, merge и deployment не выполнялись.

## Результат и границы готовности

Подготовлено **25 из 25** выбранных таксонов, **5 пакетов по 5** записей. Все 25 имеют состояние `ready_for_review` и проходят строгую модель карточки, научные ссылки, проверку материалов, лицензий и чистое планирование существующего импортёра. Технических ошибок — **0**, дубликатов с каталогом и внутри партии — **0**. `approved_for_import` — **0**, `imported` — **0**; у всех `approval:null`, `verified:false`, `lastReviewedAt:null`.

Научные утверждения связаны с проверяемыми источниками, однако **ни одна карточка не получила независимого научного или редакторского одобрения**. Все 25 требуют независимой проверки и имеют перечисленные неизвестные факты. У **5** особенно существенные пустые поля: эминиум Регеля (категория), широкотычиночный тюльпан (местообитание), варан (категория и внешность), удавчик (внешность), белоглазая чернеть (размножение). У **7** точная синонимия по GBIF требует проверки применимости исторического национального концепта к принятому имени. Эти множества пересекаются и не складываются.

Все новые материалы остаются непубличными. Каталог — прежние **40** записей; архив — **2**. Сохранены SHA-256 **153** исходных файлов, включая публичные JSON, опубликованные изображения, географию, UI и исходный мастер-реестр. Сам мастер-реестр 60 кандидатов не изменён. Карта и численность существующих видов сохранены.

## Тексты и языки

Созданы **25** коротких описаний: RU 149–167 символов. На KY/UZ/RU/EN — **по 25**, всего **100** кратких версий. Созданы **25** полноформатных русских обзоров, 144–165 слов каждый. Тематические разделы используют существующие семь ключей `shortDescription/overview/appearance/ecology/diet/reproduction/distribution`. У растений `diet:null`; неизвестная внешность, местообитание и размножение не заполняются по аналогии с близкими видами.

Полные описания: RU 25, KY 0, UZ 0, EN 0. Для длинных разделов действует существующий честный fallback на RU с указанием фактического языка. Краткие тексты переводятся напрямую, UZ — литературная латиница; русский текст в другие языковые поля не копировался. Переводы пока требуют независимого носителя языка.

Названия: RU 25, EN 18, KY 0, UZ 0. Английские названия взяты из национальных статей для совпадающих принятых таксонов; типографическое `Black Grous` нормализовано до `Black Grouse`, с исследовательским примечанием. Для семи синонимичных исторических концептов EN оставлено null. Кыргызские названия из старого шрифтового извлечения требуют отдельной вычитки; узбекские народные имена не создавались. Существующий fallback названия показывает RU с маркировкой `ru`; если все названия отсутствуют — научное имя с маркировкой `la`. Дизайн и поведение интерфейса не менялись.

Заключительная проверка английских названий была причиной обновления 18 ранее подготовленных черновиков в пятом коммите; семь остальных файлов не перезаписывались. После завершения этой проверки повторная подготовка и resume сохраняют успешные черновики.

## Изображения и лицензии

Поиск проведён для всех 25 таксонов, по принятому имени и национальному синониму, где они различаются. В кэше 44 уникальных результатов JPEG/PNG; среди них есть фотографии, иллюстрации и неподходящие изображения — результаты поиска не считаются разрешёнными фотографиями.

Подготовлено **11 WebP**; **10** включены в непубличные черновики, **1** помещён в исследовательский карантин. У **15** карточек placeholder. Внешние места съёмки и культурные экземпляры прямо указаны в подписях и не превращены в наблюдения в Кыргызстане.

Лицензионная проверка не означает научного утверждения идентификации и не даёт разрешение импорта. Ни одно новое изображение не помещалось в `public/images/approved`.

## Научные пробелы, численность и география

У эминиума: VU в RU/KY и EN в английском резюме; у варана: CR в RU и EN в английском резюме. Оба поля национальной категории оставлены null. У эремуруса Зои версии расходятся в названиях ущелий: сохранён только общий Кыргызский хребет. У ириса Колпаковского Ферганский хребет самим первоисточником назван требующим проверки и не принят как подтверждённый. У Masaris часть местных сведений зависит от предполагаемой синонимии; это отмечено отдельно.

Детальная внешность варана и удавчика не описана использованной национальной статьёй: `appearance:null`. У широкотычиночного тюльпана источник прямо не даёт местообитание: `habitat:null`. У белоглазой чернети местное гнездование только предполагалось, и неподтверждённое размножение не добавлено. Общевидовая биология савки явно отделена от кыргызстанского пролёта. Полные списки `missingFacts` и `editorialNotes` находятся в рабочем реестре и машинном отчёте.

У всех 25 `population.type:unknown`, `reviewStatus:pending`; источники численности не назначены. Отдельно сохранены старые сообщения о ленце, удавчике, тетереве, кликуне, крохале и гагаре. Единственное явно датированное из этих свидетельств — май 2003 года: три самца и одна самка тетерева на маршруте 2,5 км в восточных отрогах Кунгей Ала-Тоо. Это маршрутное наблюдение, а не оценка популяции. Недатированные числа и неопределённая география 100–4500 савок не использованы как численность страны.

География каждой карточки ограничена исторически подтверждённой страной KG; общие текстовые ареалы сохранены с источником и датировкой. Координаты, наблюдения и новые точки карты не создавались.

## Независимая проверка

Все команды выполняются из корня проекта. Эти команды ничего не импортируют:

```powershell
npm run data:bulk:check -- --registry data/research/bulk-25-content-registry.json
npm run data:bulk:report -- --registry data/research/bulk-25-content-registry.json
node --test tests/bulk-25-content.test.mjs
node scripts/check-bulk-25-content.mjs
npm test
npm run data
npm run data:validate
npm run build
```

Для восстановления checkpoint без одобрения или импорта:

```powershell
npm run data:bulk:resume -- --registry data/research/bulk-25-content-registry.json
```

При обоснованном редактировании фактов одного блока — например, `node scripts/prepare-bulk-25-content.mjs 3`, затем `data:bulk:check --batch 3` и `resume`. Неизменённые файлы черновиков переиспользуются. Этот помощник только создаёт данные species; проверка, checkpoint и публикационные решения остаются в существующем `data:bulk:*`. Второй импортёр не создан.

## Будущий контролируемый импорт — команды не выполнялись

Сначала независимый специалист проверяет исходные статьи, синонимию и национальный охват, разрешает существенные расхождения, проверяет переводы и каждый выбранный снимок. После изменения материалов нужно снова выполнить `check/resume`: старое разрешение по прежнему fingerprint недействительно. Каждое одобрение должно содержать реальное имя редактора, дату и конкретное обоснование; приведённая команда — шаблон, а не разрешение всем 25.

```powershell
npm run data:bulk:approve -- --registry data/research/bulk-25-content-registry.json --candidate eremurus-zenaidae --reviewer "ИМЯ НЕЗАВИСИМОГО РЕДАКТОРА" --date YYYY-MM-DD --reason "КОНКРЕТНОЕ ОБОСНОВАНИЕ ПОСЛЕ ПРОВЕРКИ"
npm run data:bulk:check -- --registry data/research/bulk-25-content-registry.json --batch 1
npm run data:bulk:apply -- --registry data/research/bulk-25-content-registry.json --batch 1
```

`apply` используется только после отдельного разрешения пользователя на импорт, на разрешённой ветке, и включает только записи с действующим индивидуальным одобрением. Повторяется отдельно для нужных блоков 2–5. Подготовленные `block-N-drafts.json` имеют защищённый тип `research-draft-batch`; менять его вручную на импортный или запускать старый импортёр в обход проверки нельзя. Независимое одобрение импорта само по себе не меняет `verified:false` и не утверждает численность.
