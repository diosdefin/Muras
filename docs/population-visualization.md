## Контракт population

```json
{
  "type": "unknown",
  "value": null,
  "min": null,
  "max": null,
  "territory": null,
  "year": null,
  "unit": null,
  "sourceIds": [],
  "reviewStatus": "pending",
  "method": null
}
```

- exact: value — положительное безопасное целое, min/max:null,
  method:complete-count. Это документированный полный подсчёт соответствующей
  территории/единицы, а не оценка, случайно записанная целым числом.
- approximate: конечное неотрицательное value ИЛИ min/max с min ≤ max; method:estimate.
  Одиночное значение имеет ≈, диапазон — обе границы без среднего. Подтверждённый ноль
  допустим только как самостоятельная оценка с источником; unknown нулём не заменяется.
- unknown: value/min/max/method:null. Метаданные могут быть null; чисел нет.
- Известное значение всегда требует territory, year (1500..текущий год), unit и sourceIds.
  Каждый заполненный научный путь (population.type/method/value/min/max/territory/year/unit)
  должен подтверждаться хотя бы одним из выбранных источников через sources.supports.
- reviewStatus: pending/approved/rejected. Известные pending/rejected сохраняются в данных,
  но интерфейс не публикует число и показывает необходимость проверки. Даже approved
  не обходит валидацию; malformed отклоняется загрузчиком/генератором, представление
  дополнительно возвращает unknown. Проверка оценки не меняет verified всего вида.

Все девять видов и два архивных примера остаются unknown. Единственная структурная
миграция — удаление пустой estimate:null и добавление явных полей. Численные факты
не добавлены. Внешняя schemaVersion документа остаётся 1; внутренний контракт population
обновлён согласованно в редакторском источнике, генераторе и интерфейсе. Старые known
форматы exact/range не преобразуются автоматически и отклоняются новым валидатором.

Научный блок показывает значение, точность, территорию, год, единицу и ссылки.
Мировой подсчёт не называется численностью Кыргызстана: исходная территория отображается
дословно. Нет формулировки «осталось всего» и вывода о вымирании из отсутствия оценки.

Для exact до 100 — отдельная ячейка на единицу учёта, включая ровно 3/17/99.
Больше 100: не более 100 ячеек, масштаб ceil(value/100), остаток последней ячейки
показан текстом; сумма не меняется. Для approximate/unknown таких ячеек нет.
Ячейки декоративны (aria-hidden); значение и масштаб доступны текстом.

## Получение данных и будущий API

loadSpeciesCatalog({url, fetcher, signal}) возвращает валидированные записи, не Vue-состояние.
Пока URL указывает на локальный JSON с Vite BASE_URL. Django REST API позже может
заменить URL/транспорт и предоставить тот же массив. Серверная авторизация редактора,
подтверждение публикации, журнал аудита, согласование источников и миграция API-контракта
остаются будущими задачами; клиентский reviewStatus сам по себе не защищает админку.
Scientific type/method и редакторское approved должны задаваться людьми, проверившими
методику первоисточника. Автоматическая валидация этого не доказывает.

## Эффекты и ресурсы

Чёткая цветная фотография → пауза 450 мс после загрузки → плавный переход 900 мс.
unknown: grayscale от 0 до 1, полный исходный crop, без уменьшения детализации.
exact/approximate: символическое уменьшение детализации до 24 колонок; алгоритм
не получает value/min/max и не связывает их с пикселями. Обратное действие возвращает
исходную чёткость и цвет. Кнопка остаётся тем же DOM-элементом и не теряет фокус.
При prefers-reduced-motion переход мгновенный; короткая автоматическая пауза сохраняется.
В каталоге фотографии всегда цветные и чёткие. Placeholder не анимируется.
Если Canvas filter отсутствует, unknown использует CSS grayscale на Canvas с тем же
параметром перехода; пикселизация и разрешение от этого не меняются. Fallback проверен тестом.

Обычный кадр использует cover + прежние composition.x/y/zoom. Canvas получает
эквивалентный compositionCrop с тем же aspect 4:3 и оригинальным WebP, не preview.
Каждая обработка берёт неизменённый источник. Авторство/лицензия остаются доступными;
условный эффект и редакционное кадрирование обозначены в интерфейсе.

Один RAF одновременно; resize-события объединяются. После завершения нет постоянного
цикла. IntersectionObserver и document.visibilitychange приостанавливают невидимый
интерактив; при возвращении он продолжает переход. Нулевой размер останавливает работу
до resize. DPR ≤ 2, длинная сторона ≤ 1800, площадь около 2 млн пикселей (округление).
При закрытии/смене записи очищаются RAF, таймер, обработчики изображения и backing stores.
Устаревшие callbacks защищены поколением загрузки. Изменение языка не перезапускает эффект.
