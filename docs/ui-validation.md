# Интерфейс Redbook — задача №3

Проверено 12 октября 2026 года в локальном Chromium через production preview.
Научные записи, валидатор и генерируемые JSON не изменялись. Новых зависимостей нет.

## Адаптивность и взаимодействия

| Viewport | Страница: scrollWidth/clientWidth | Переполнение dialog / содержимого |
|---|---|---|
| 320 × 720 | 305 / 305 | 0 / 0 |
| 375 × 812 | 360 / 360 | 0 / 0 |
| 768 × 1024 | 753 / 753 | 0 / 0 |
| 1024 × 768 | 1009 / 1009 | 0 / 0 |
| 1440 × 900 | 1425 / 1425 | 0 / 0 |
| 1920 × 1080 | 1905 / 1905 | 0 / 0 |

Разница с шириной viewport — вертикальный scrollbar, а не горизонтальное переполнение.
На всех размерах проверены пустой результат фильтра EN, возврат к VU и фильтр
Кыргызстан; открытие Enter; перевод заголовка на кыргызский и английский;
границы ползунка 8/200; цикл Shift+Tab с кнопки закрытия к последнему источнику
и Tab обратно; Escape и восстановление фокуса на кнопку карточки. Все прошли.
Границы dialog находятся внутри viewport; canvas помещается в контейнер.

На 320 px дополнительно проверены Space, кнопка закрытия, backdrop со всех
четырёх сторон и отсутствие закрытия при нажатии внутри окна. Skip-link с
клавиатуры переносит фокус к каталогу. Кнопки управления имеют высоту 48 px,
ссылки источников — не менее 44 px. Последний источник доступен через прокрутку.

Прокрутка внутри modal-scroll достигла 907 px, фон остался зафиксированным:
body.top = -1209.5 px. После закрытия позиция страницы восстановилась до 1209.5 px.
При открытии dialog соответствует :modal, фокус находится на кнопке закрытия.
showModal блокирует взаимодействие с фоном; дополнительно зафиксированы body
и прокрутка корневого элемента. Длинные текстовые поля переносятся через
overflow-wrap:anywhere, колонки используют minmax(0,1fr).

Console warn/error во время проверок: отсутствуют.

## Контраст и предпочтения

Контраст вычислен для цветов CSS по относительной яркости sRGB:

| Назначение | Цвета | Контраст |
|---|---|---|
| Основной текст | #253B32 / #F7F8F4 | 11.25:1 |
| Вторичный текст | #526258 / #F7F8F4 | 6.06:1 |
| Вторичный текст на карточке | #526258 / #FFFFFF | 6.47:1 |
| Красный акцент | #B94D48 / #F7F8F4 | 4.67:1 |
| Статус VU | #715027 / #F6EFDF | 6.37:1 |
| Выбранный язык | #FFFFFF / #253B32 | 12.00:1 |
| Граница select/кнопок | #839388 / #FFFFFF | 3.23:1 |

#68816E используется для декоративных линий, иллюстрации и track ползунка;
обычный мелкий текст использует более тёмный #526258.
color-scheme:light подтверждён вычисленным стилем браузера. Видимый красный
focus проверен с клавиатуры. prefers-reduced-motion отключает переходы,
анимации и плавную прокрутку; forced-colors возвращает системный range.
Эти два режима проверены по CSS, без переключения системных настроек.

## Повторная проверка

1. Выполнить npm test, npm run data, npm run build.
2. Запустить npm run preview -- --host 127.0.0.1 --port 4173 --strictPort.
3. Повторить сценарии выше на указанных размерах.
4. Проверить нулевой diff файлов data/species.source.json, public/data/species.json,
   data/archive/demo-species.generated.json и src/data/species-model.js.

Снимки главной страницы и modal до/после, а также мобильных состояний сохранены
в артефактах чата вне репозитория. Проверка не является сертификацией WCAG.
Реальные iOS/Android устройства, Safari, Firefox и screen reader не тестировались.
