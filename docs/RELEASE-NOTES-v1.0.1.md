# MURAS 1.0.1

An educational atlas of the rare species and protected territories of Kyrgyzstan. A static single-page web app (Vue 3 + Vite) with a four-language interface (Kyrgyz, Russian, Uzbek, English).

## Highlights
- 184 documented species records with sources, national and IUCN status and licensed photographs.
- Interactive regional map with 208 documented occurrence links; protected territories section.
- Quiz and lesson mode; installable offline PWA with lightweight photo copies for slow connections.
- Provenance-first data pipeline with SHA-256 receipts; history-independent test suite (480 tests) and CI.
