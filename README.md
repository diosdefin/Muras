# Muras — природное наследие Кыргызстана

**MURAS** — образовательная цифровая платформа о природном наследии и редких видах
Кыргызстана. Кыргызское название — «Мурас», слоган — «Жаратылыш — биздин мурас».
«Красная книга Кыргызстана» — тематический каталог платформы. Muras не является
официальным государственным изданием или государственным сервисом.

Брендовый SVG-знак и favicon созданы для проекта; главная композиция, горы и палитра
сохранены. Подписи и метаданные поддерживают KY/UZ/RU/EN, первый визит — KY.
Результаты ребрендинга: [docs/branding-validation.md](docs/branding-validation.md).
Исторические ключи `redbook.*`, имя npm-пакета, ID источников и пути репозитория
сохранены для совместимости; они не являются публичным названием платформы.

Готовность конкурсной сборки, измерения Lighthouse и известные ограничения:
[docs/release-readiness.md](docs/release-readiness.md).
Ручная проверка устройств, хостинга и полного цикла админки:
[docs/manual-qa-checklist.md](docs/manual-qa-checklist.md).
Настройки Vercel, первая публикация из `main` и откат:
[docs/vercel-deployment.md](docs/vercel-deployment.md).
Архитектура восьми групп для постепенного расширения каталога и совместимость старых ID:
[docs/catalog-expansion.md](docs/catalog-expansion.md).

Vue 3 / Vite / Tailwind. Каталог этой ветки содержит **30 национальных записей**:
6 млекопитающих, 7 птиц, 7 растений, 2 рыбы, 2 пресмыкающихся,
1 земноводное, 3 членистоногих и 2 гриба. У 21 записи есть локальное разрешённое
фото, у девяти — честный placeholder. Две новые записи относятся к подвидам.
Пакетный импорт, причины девяти отсрочек и проверка следующей партии:
[docs/research/bulk-expansion-validation.md](docs/research/bulk-expansion-validation.md).
Первая партия из восьми добавленных видов и её ограничения:
[docs/research/first-batch-validation.md](docs/research/first-batch-validation.md).
`verified: false` сохраняется до независимой научной редакторской проверки. Национальные
категории относятся к изданию 2006 года; глобальные IUCN указаны отдельно. Это учебный
проект, не официальное новое издание Красной книги. Викторина содержит 18 вопросов
по сведениям и источникам существующего каталога.

## Запуск и проверки

Проверенное окружение: Node.js 22.20.0, npm 11.12.1. Новые npm-зависимости при миграции
не добавлялись. Python не нужен для сборки и работы каталога.

```bash
npm ci
npm run dev
npm run data:validate
npm test
npm run build
npm run preview
```

`predev` и `prebuild` валидируют JSON каталога и вопросов, заново создают публичные проекции
и копируют только фотографии с подтверждёнными правами. Некорректная структура
останавливает запуск/сборку с указанием поля. `data:validate` дополнительно проверяет,
что сохранённые generated-файлы соответствуют источнику и нет устаревших публичных фото.

## Единственный источник данных

Редактируйте **только `data/species.source.json`**. Корень: `schemaVersion: 1`,
`catalog` (национальные кандидаты/проверенные записи), `demoArchive` (бывшие
демонстрационные примеры, не публикуются).

```bash
npm run data:generate
```

Генерируемые файлы, которые нельзя редактировать независимо:

- `public/data/species.json` — только catalog, без неподтверждённых фотографий;
- `data/archive/demo-species.generated.json` — архив тигра и журавля, вне public;
- `public/images/approved/` — только текущие разрешённые фото. При отзыве подтверждения
  лицензии следующая генерация удаляет устаревший публичный файл.

Модель и правила источников описаны в [docs/data-model.md](docs/data-model.md).
Валидатор общий для генератора и загрузки Vue: `src/data/species-model.js`.
Проверка структуры и наличие URL **не доказывают истинность источника**: содержимое
документов и соответствие утверждения источнику проверяются редактором.

## Образовательная викторина

Редактируйте только `src/data/quiz/questions.json`: 18 вопросов, по 6 на уровнях
«Начинающий», «Исследователь», «Эксперт». `public/data/quiz.json` генерируется командой
`npm run data`; это не второй редактируемый источник. Оба набора валидируются до записи
публичных файлов. Проверяются виды, источники, подтверждаемые поля (`factPaths`), четыре
различных варианта и ссылка на разрешённую фотографию.

За попытку выбирается до 10 разных вопросов уровня, сейчас доступно по 6. Вопросы и
ответы перемешиваются. После ответа доступны объяснение, источники и запись вида.
Можно пройти заново или повторить только ошибки и пропуски. При потере фотографии
появляются placeholder и возможность пропустить вопрос без балла. Последние 20 итогов
сохраняются локально; при недоступном хранилище прохождение продолжает работать.
Переход в каталог сохраняет попытку до перезагрузки страницы. Все 18 вопросов имеют
версии на русском, кыргызском и английском с общими идентификаторами ответов.

Логика отделена от Vue-интерфейса; научный статус записей не меняется. Валидация ссылок
не заменяет редакторскую проверку содержания вопросов. Подробности и результаты
проверок: [docs/quiz-validation.md](docs/quiz-validation.md).

## Языки интерфейса

Единственный переключатель KY/UZ/RU/EN находится в шапке. Для нового посетителя выбран
кыргызский язык независимо от языка браузера; выбор сохраняется в `redbook.locale.v1`.
Переключение не перезагружает приложение и сохраняет фильтры, карту и попытку викторины.
Словари редактируются в `src/locales/{ky,uz,ru,en}.json`; `data:validate` и production-сборка
проверяют совпадение ключей, параметров и существование статических ключей в интерфейсе.

Поиск остаётся многоязычным. Карточка, открытая по однозначному совпадению названия,
получает временный язык этого совпадения. Латинские, нечёткие и неоднозначные совпадения
используют язык сайта. Язык остального интерфейса при этом не меняется.

Научные сведения без перевода показываются в оригинале с пометкой языка. Источники и
лицензии не переводятся автоматически; альтернативный адрес документа используется
только при явном подтверждении в метаданных. Полнота переводов, сценарии проверки и
задачи для редакторов: [docs/localization-validation.md](docs/localization-validation.md).
UZ использует узбекскую латиницу. Переведены 442 ключа публичного интерфейса,
168 ключей админки и 18 вопросов. Неподтверждённые узбекские названия видов не создаются;
старые научные записи используют явный fallback. Подробности и проверки:
[docs/uz-localization-validation.md](docs/uz-localization-validation.md).

## Энциклопедические тексты

Все 30 существующих записей имеют отдельный `content`, который не заменяет
`habitat`. Краткие знакомства с организмами доступны на KY/UZ/RU/EN;
полные русские обзоры и тематические разделы на остальных языках используют
помеченный fallback. Неизвестные сведения остаются null, все `verified:false`.
Карточка показывает краткий текст, диалог — первый абзац обзора, страница вида —
полный материал со ссылками. Админка и валидируемый импорт/экспорт поддерживают
новые разделы. Научные ограничения и таблица покрытия всех записей:
[docs/research/species-content-30-validation.md](docs/research/species-content-30-validation.md).

## Режим урока

Пункт «Режим урока» открывает презентацию всех опубликованных видов: крупная фотография,
названия RU/KY/Latin, краткие выдержки, категории и ссылки на источники. Полные сведения,
численность, таксономия и атрибуция раскрываются по запросу. Новые научные тексты не
генерируются; статус необходимости редакторской проверки остаётся видимым.

Выбирайте вид из списка или кнопками «Назад»/«Далее»; после последнего снова идёт первый.
При фокусе на слайде действуют ←/→ и Escape (возврат в каталог). Поля и интерактивные
элементы сохраняют обычное управление. «На весь экран» вызывает Fullscreen API только
после нажатия. Если API недоступен/запрещён, урок продолжается в обычном окне. В полном
экране Tab удерживается среди доступных элементов урока. Кнопка выхода из полного
экрана сохраняет урок; внешний выход браузера завершает презентацию и возвращает каталог.

Из урока запускается существующая викторина, с возвратом к выбранному виду во время
прохождения и на итоговом экране. Выбранный вид сохраняется до перезагрузки страницы.
Проверки, проекторные размеры и ограничения: [docs/lesson-validation.md](docs/lesson-validation.md).

## Фотографии и учебная пикселизация

Для каждого фото в источнике есть path, author, originalPage, license, licenseUrl,
attribution, modifications и licenseVerified. Неизвестные метаданные — null.
`licenseVerified: true` допустим только после реальной проверки условий. Даже полные
строковые метаданные сами по себе не подтверждают права. Исходный путь — внутри проекта,
вне public; публичный путь назначает генератор. Девять разрешённых WebP находятся в
`assets/images/species/`; их размеры, подписи и SHA-256 есть в основном JSON. Генератор
проверяет наличие/контрольную сумму и копирует их в public. Происхождение, лицензии,
контекст съёмки и сомнения описаны в [docs/species-research.md](docs/species-research.md).
Для фото без подтверждённых прав остаётся собственный SVG условного горного пейзажа
(`public/images/placeholder.svg`). Старые изображения из backup не публикуются.

Запись сначала показывает чёткий цветной кадр с существующей редакционной композицией.
Через короткую паузу unknown становится чёрно-белым без потери детализации;
подтверждённые exact/approximate используют символическую пикселизацию без связи
числа пикселей с числом особей. Ползунка нет; «Показать чётко» / «Показать визуализацию»
переключают представление, reduced motion отключает анимацию. Для фото без подтверждённых
прав показан placeholder, интерактив отключён. Canvas использует качественный локальный
WebP, а не уже пикселизированный PNG. Автор, оригинальная страница, лицензия и изменения
показаны в интерфейсе. Адаптации BY-SA сохраняют ту же лицензию; условия относятся
к конкретному изображению, не ко всему коду сайта.

Дополнительные локальные previews (не требуются для build):

```bash
pip install -r scripts/requirements.txt
npm run data:images
```

`scripts/process_data.py` читает тот же основной JSON, проходит общий Node-валидатор,
обрабатывает только разрешённые фотографии и пишет `.generated/images`. Публичный JSON
он не изменяет. Для нынешнего каталога создаются 9 previews. Pillow
импортируется только при обработке. Проверено с Python 3.13.3 и Pillow 11.1.0.

Оптимизация нового разрешённого файла тем же инструментом (метаданные и условия
использования редактор записывает в основной JSON отдельно):

```bash
python scripts/process_data.py --optimize-input original.jpg --optimize-output assets/images/species/example.webp --max-edge 1200 --quality 82
```

Это локальная операция без публикации/изменения научных записей. Она печатает размеры,
SHA-256 и размер файла; не увеличивает исходное изображение. Добавляйте только файлы,
права на которые реально проверены, затем запускайте `npm run data`.

## Что подтверждено

Для исходных девяти видов: включение в перечень постановления №170 в редакции 2009 года,
встречаемость в Кыргызстане и описания по второму изданию Красной книги (2006), названия
RU/KY/EN, таксономическая концепция и глобальная категория из собственного набора IUCN
в GBIF (версия 2026-1). Национальная категория архара оставлена null из-за разных
категорий подвидов; у остальных восьми указана категория именно национального издания.
Ссылки и перечень поддерживаемых полей находятся в sources, доступны в модальном окне.

Все численности и годы индивидуальных оценок IUCN остаются null. Наблюдения на маршрутах
не заменяют учёта популяции; год публикации набора не заменяет год оценки вида.
Точные сведения об источниках, расхождениях GBIF и фотографиях — в
[отчёте исследования](docs/species-research.md), снимки API — в `docs/evidence/`.
Новые описания доступны по-русски; отсутствующие переводы ky/en не сочинены.
`lastReviewedAt` — дата частичного просмотра источников, не дата учёта и не гарантия
полной независимой проверки. `verified` остаётся false у всех 30 записей.

В архиве журавля подтверждены научное/английское имена, часть таксономии и IUCN EN
по CMS. Старый CR не перенесён. Тигр оставлен архивным неподтверждённым примером;
его исходные имена и сведения полностью сохранены в резервном JSON, а в новой модели
неподтверждённые поля — null.

## Резервная копия

`data/backups/legacy-2026-10-12/` хранит исходный JSON, старый Python-скрипт и все
исходные/обработанные фото. SHA-256 записаны в manifest.json и проверяются тестами.
У журавля сохранены EXIF автора jimkruger и copyright jim kruger; это не лицензия.
Резервная копия не участвует в генерации научных записей и не попадает в dist.
Восстановление описано в README этой папки. Полная прежняя версия остаётся также
в Git-коммите `5d1f5e6` и в неизменённой ветке main.

## Размещение

Публикуйте только `dist`, не весь репозиторий. Для корня домена достаточно стандартной
сборки. Для подпапки согласуйте Vite base, например `npm run build -- --base=/redbook/`.
Vue использует BASE_URL для данных и изображений. Не открывайте index.html через file://:
запускайте HTTP-сервер. Проверка реального хостинга не входит в эту миграцию.

## Интерфейс и проверки

Светлый интерфейс использует системные шрифты и лёгкие SVG-иллюстрации. Нативное
модальное окно фиксирует фон, удерживает фокус и восстанавливает его при закрытии.
Результаты проверки адаптивности, клавиатуры и контраста: [docs/ui-validation.md](docs/ui-validation.md).
Команда `npm run data` запускает тот же генератор, что и `npm run data:generate`.

Настройки композиции фотографий, устройство Canvas и результаты
проверок прежнего интерактива: [docs/visualization-validation.md](docs/visualization-validation.md).
Текущая модель численности, автоматические эффекты, ячейки полного подсчёта и проверки:
[docs/population-visualization.md](docs/population-visualization.md). Все 30 записей пока
имеют type:unknown. Реальные оценки не добавлены; reviewStatus отделён от verified вида.
Загрузка и валидация каталога вынесены в `src/data/catalog-repository.js`; будущий API
должен поставлять ту же модель, а не менять логику компонентов.

## «Сохрани вид» и демонстрационная стена

Отдельный раздел поддержки доступен из навигации и кнопки «Помочь сохранить вид»
в научной карточке. Использует существующие фото, угрозы, меры охраны и источники.
Приём пожертвований пока не открыт: платежей, сумм, рейтингов и прогресса сбора нет.

Стена хранит только выдуманные демопсевдонимы локально в `redbook.support.demo.v1`.
Есть общий список и список выбранного вида, удаление записи и очистка. Другие
посетители сайта их не видят; имена не отправляются на сервер. Не вводите личные
сведения. Демозапись не является пожертвованием или согласием на публичную публикацию.

Будущая организация, безопасное подтверждение платежей, модерация, отзыв согласия
и отчётность описаны в [docs/support-architecture.md](docs/support-architecture.md).
Результаты проверок: [docs/support-validation.md](docs/support-validation.md).

## Компактный каталог и поиск

Поиск работает локально по KY/UZ/RU/EN и научным названиям, учитывает регистр, пробелы,
ё/е, варианты апострофа в oʻ/gʻ и ограниченные латинские варианты кыргызских названий. Небольшие опечатки дают
помеченные вероятные совпадения; точные результаты имеют приоритет. Подсказки доступны
со стрелками, Enter и Escape, используют те же фильтры, что и каталог.

IUCN показывает только имеющиеся категории; группы доступны кнопками, сохранён регион
и общий сброс. Карта сохраняет интерактивный SVG и предлагает семь кнопок выбора областей.
Каталог из 30 записей показывает 12 карточек, затем 24 и 30 по кнопке «Показать ещё».
Подробные научные сведения и атрибуция фото доступны в раскрываемых секциях диалога.
Механизм, результаты проверок и ограничения: [docs/catalog-ux-validation.md](docs/catalog-ux-validation.md).

## Ограничения текущего этапа

Карта семи областей расположена между главным экраном и каталогом. Использует
локальные границы geoBoundaries за 2017 год (ODbL 1.0) и отдельные региональные
свидетельства из `data/geography/occurrences.source.json`. Каталог не используется
для угадывания областей. Источники, лицензия, две подтверждённые по публикации
связи и ограничения: [docs/map-research.md](docs/map-research.md).
Команды `npm run data`, `data:validate` и `build` теперь проверяют также карту;
редактировать сгенерированные файлы `public/data/geography/` не следует.

Интерфейс поддерживает KY/UZ/RU/EN; независимая научная редактура остаётся отдельной задачей.
Национальные статусы имеют исторические первоисточники, но современная правовая редакция
и датированные оценки численности пока не исследованы. Фото иллюстрируют вид, не
кыргызстанскую популяцию: снимки в неволе, ботанических садах и других странах явно
подписаны. Интерфейс проверяется в Chromium на шести размерах экрана; проверка реальных
устройств и screen reader ещё не проведена. Автоматическая валидация не заменяет редактора.

## Локальная панель редактора

Панель открывается по `/admin` (без ссылки в публичном меню). У неё нет авторизации:
скрытый адрес не защищает данные. Она редактирует только импортированный полный
`data/species.source.json`, сохраняет локальные черновики и экспортирует JSON.
Публичный сервер и файлы репозитория из браузера не изменяются.

Есть шесть вкладок научных данных, отдельная проверка численности и визуальный
редактор фото с композициями карточки, подробного окна/Canvas и урока. Фотографии
остаются локальными предпросмотрами до подготовки файлов в проекте; права проверяет
редактор. Архив и неизвестные исходные поля сохраняются при экспорте.

Инструкция импорта, подготовки фото, публикации, особенности статического хостинга
и результаты проверок: [docs/admin-validation.md](docs/admin-validation.md).
План перехода на Django REST без замены Vue:
[docs/backend-migration.md](docs/backend-migration.md).
