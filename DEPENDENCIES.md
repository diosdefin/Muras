# MURAS — зависимости и установка

Проект работает на **Vue 3 + Vite**. Основной менеджер зависимостей — **npm**.

## Какие файлы отвечают за зависимости

| Файл | Назначение |
| --- | --- |
| `package.json` | Прямые зависимости, dev-зависимости и команды запуска. |
| `package-lock.json` | Зафиксированные версии полного npm-дерева; обеспечивает воспроизводимую установку через `npm ci`. |
| `.nvmrc` | Рекомендуемая версия Node.js для разработки: `22.20.0`. |
| `scripts/requirements.txt` | Python-зависимости **только** для необязательного скрипта обработки изображений. |

Устанавливать `node_modules` вручную или добавлять эту папку в Git **не нужно**.

## Установка после `git clone`

Нужны Node.js 22 (рекомендуется 22.20.0) и npm. В исходном README зафиксирована проверенная конфигурация: Node.js 22.20.0 / npm 11.12.1.

```powershell
# После клонирования и перехода в каталог MURAS:
node --version
npm --version
npm ci
npm run dev
```

Локальный адрес после запуска покажет Vite (обычно `http://localhost:5173/`).

## Перед публикацией

```powershell
npm test
npm run data
npm run data:validate
npm run build
```

Публикацию в `main` проводите **только после прохождения тестов**. Эти команды не устанавливают новые зависимости и не меняют `package.json`/`package-lock.json`.

## Прямые npm-зависимости проекта

Для сайта:
- `vue` — `^3.5.13`.

Для разработки и production-сборки:
- `vite` — `^6.0.5`;
- `@vitejs/plugin-vue` — `^5.2.1`;
- `tailwindcss` — `^3.4.17`;
- `postcss` — `^8.4.49`;
- `autoprefixer` — `^10.4.20`.

Это диапазоны из `package.json`. **Конкретные устанавливаемые версии** и транзитивные пакеты определяет `package-lock.json`; не редактируйте lock-файл вручную.

## Необязательная обработка изображений на Python

Обычная установка, запуск Vite и production-сборка **не требуют Python**. Только если вы запускаете `npm run data:images`, дополнительно нужен Python с Pillow:

```powershell
python -m pip install -r scripts/requirements.txt
npm run data:images
```

На момент этого документа в `scripts/requirements.txt` указан `Pillow==11.1.0`.

## Не включайте в репозиторий

Папки `node_modules/`, `dist/`, `__pycache__/` и `*.pyc` игнорируются через `.gitignore`. После клонирования сначала выполните `npm ci`, затем работайте с проектом.
